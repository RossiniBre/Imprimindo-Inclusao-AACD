TELA: Painel da AACD (Acompanhamento)
Quem acessa: funcionários da AACD e admin. Rota: #/painel-aacd (o login manda o FUNCIONARIO para cá).
O que faz: lista todos os pedidos de impressão em quatro seções, pelo status do back:
  Esperando aceite (PENDENTE) · Imprimindo (EM_ANDAMENTO) · Prontas (CONCLUIDA)
  Recusadas (RECUSADA, CANCELADA e FALHOU, cada uma com o próprio chip e o motivo).
Os contadores do topo filtram a lista (clicar de novo, ou "Ver todos os pedidos", mostra tudo).
Cada seção mostra até 4 cartões e o botão "Ver todos (n)" abre o resto.
Cada cartão mostra o número do pedido, título, empresa, impressora e quem enviou.
Imprimindo: barra de progresso da aceitação até o prazo estimado pela empresa.
Ações: Cancelar pedido (só pendente) e Remover (pronta ou recusada), com modal de confirmação.
"+ Nova solicitação" leva para #/impressoras-aacd (a criação do pedido é no modal de lá) e
"Escolher outra empresa" leva para #/reescolher-empresa?pedido=ID (reenvio do pedido recusado).

Rotas do back usadas (via shared/js/api.js):
  GET  /api/solicitacoes          -> lista (todos os pedidos para AACD)
  GET  /api/solicitacao/ver?id=   -> detalhe, usado só para pegar prazoEstimado
  POST /api/solicitacao/cancelar  -> { id } (PENDENTE; EM_ANDAMENTO só admin com justificativa)
  POST /api/solicitacao/excluir   -> { id } (não aceita PENDENTE nem EM_ANDAMENTO)
Sem sessão (401) a tela redireciona para #/login.
Regras do back usadas nos textos: pendente expira em 30 dias; prontas/recusadas somem em 60 dias.

Pendente / fora do back:
  - "Reenviar pedido" (pendente) e "Marcar como retirada" do Figma não existem no back; ficaram de fora.
  - Cancelar pedido em andamento (só admin, com justificativa) não está na tela.
